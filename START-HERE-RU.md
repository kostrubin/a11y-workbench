# A11y Workbench — продолжение существующей Cloud-разработки

Владелец выбрал существующий Cloud workspace этого проекта и разрешил реализацию прямо в нём. Новую среду, отдельную конкурирующую задачу и вложенный Codex создавать не нужно. На компьютере владельца реализацию и тестирование не выполнять.

Название среды и метаданные Only me остаются UNVERIFIED, если интерфейс их не показывает. Это не новое изменение безопасности и не причина снова запрашивать согласование выбранного workspace. Сохраняй текущие настройки доступа, сети и sandbox.

## Текущее состояние

Приложение, shared core, CLI захвата, 15 статических маршрутов и тесты реализованы. Сборка, строгая типизация, линтер и 49 небраузерных тестов прошли. Код остаётся кандидатом в разработке: браузерная приёмка заблокирована, а не пройдена.

Закреплённый Chromium не скачивается: cdn.playwright.dev возвращает 403 Domain forbidden. Browser doctor и реальная попытка E2E завершились до проверки интерфейса из-за отсутствующего binary. Скриншоты, реальные axe captures, keyboard/zoom/human AT и браузерные privacy/performance проверки не объявлять выполненными. Полная таблица — docs/VERIFICATION.md.

## Как продолжать агенту

1. Прочитать AGENTS.md, полный актуальный CODEX-IMPLEMENTATION-PROMPT.txt, docs/PROGRESS.json, docs/DECISIONS.md, docs/VERIFICATION.md и названные контракты.
2. Проверить текущую ветку work и git status; сохранить последующую работу. Не восстанавливать старый seed поверх реализации.
3. Использовать существующий Cloud workspace и уже закреплённые зависимости. При необходимости воспроизвести npm ci, npm run build, npm run typecheck, npm run lint и npm test.
4. Продолжить заблокированные браузерные проверки после поддержанного решения конкретной проблемы browser/runtime. Не расширять сеть и не отключать sandbox без решения владельца.

Оригинальный ZIP и внешний bootstrap — исторический снимок. Его старые требования приватного репозитория и отдельного запуска не заменяют актуальные инструкции. Полный промт находится в репозитории; сокращённый пересказ не является его заменой.

## Исходники и релиз

kostrubin/a11y-workbench остаётся публичным open source репозиторием. Проверенные исходники, документацию, тесты и синтетические примеры разрешено коммитить и отправлять обычным push в work без повторного согласования. Перед отправкой проверять файлы и подготовленные коммиты. Не публиковать секреты, токены, реальные отчёты, персональные данные, приватные идентификаторы чатов или чувствительные логи. Сохранять MIT и обязательные уведомления зависимостей; не использовать force push и не обходить защиту веток.

Разрешение на исходники не включает деплой, публичные preview, GitHub Releases, публикацию пакетов, индексацию или дополнительные расходы. SITE_RELEASE_APPROVED=false, SITE_PUBLIC_ORIGIN пустой, NEXT_TELEMETRY_DISABLED=1. Не активировать потенциально платный CI.

## Восстановление

Продолжать тот же существующий workspace и ветку. CONTINUE-CLOUD-TASK.txt содержит правила продолжения. Сохранять точные команды, результаты и следующий шаг. PASS, FAIL, BLOCKED и NOT RUN различаются; подготовительные тесты архива не являются тестами приложения.
